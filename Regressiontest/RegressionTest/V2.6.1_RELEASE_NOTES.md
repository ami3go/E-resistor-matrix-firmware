# E-Resistor Regression Test v2.6.1

## Corrected

- Added in-place upgrade cleanup for obsolete Python, Arduino CLI, source-build, and source-check files.
- Preserves `.venv`, `results`, `baselines`, and `bench_config.local.bat`.
- Fixed Windows bench-config path creation.
- Reworked setup error handling to avoid stale `%errorlevel%` expansion.
- Offline CRLF validation now checks only project-owned BAT files, never `.venv` or `site-packages`.
- Evidence log handlers are explicitly closed before temporary-directory cleanup and evidence hashing.
- Removed obsolete `source_check` test expectations.
- Every run writes `software_versions.json` and `software_versions.md`, including regression, Robot Framework, Python, PySerial, PyVISA, firmware, serial number, and SCPI identity/version when reachable.

## Scope

Profiles included: `read_only`, `safe_output`, and `hil_single_channel`. The dedicated Gate 3 fault-injection profile is not reconstructed in this maintenance package because its v2.6.0 implementation source was not included in the supplied package.
