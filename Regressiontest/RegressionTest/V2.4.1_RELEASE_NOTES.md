# E-Resistor Regression Test v2.4.1

## Added regression coverage

- `SCPI-006`: invalid command lengths at 1, 31, 63, 127, 128, 191, 192, 193 and 220 bytes, with a fresh-connection `*IDN?` recovery check after each case.
- `SCPI-007`: calibration values must be finite, positive, and strictly increase from bit 0 to bit 15 on every channel.
- `SAFE-003`: channel address boundaries; CH1 and CH8 accept a zero mask while CH0 and CH9 must be rejected.
- `SAFE-004`: mask input boundaries; valid `0000` is accepted while over-width zero, trailing-garbage and non-hex values must be rejected without output actuation.
- `SAFE-005`: individual zero-mask sweep across CH1 through CH8.
- `HIL-008`: guard-band audit identifying the physical measurement closest to the accuracy and stability limits.
- `BND-001..005`: deterministic boundary classification for accuracy, stability, OFF resistance, heap drift and baseline latency regression.

## Boundary semantics

Configured pass limits are inclusive:

- Absolute resistance error passes at exactly `HIL_ERROR_LIMIT_PERCENT`.
- Relative sample standard deviation passes at exactly `HIL_STABILITY_PERCENT`.
- OFF resistance passes at exactly `HIL_OFF_MIN_OHM`; positive DMM overload/open infinity also passes.
- Heap decline passes at exactly `HEAP_DRIFT_LIMIT_BYTES`.
- Baseline latency regression passes at exactly `LATENCY_REGRESSION_PERCENT`.

Each classifier is checked immediately below, exactly at, and immediately above its threshold. The boundary tests call the same shared functions used by live regression checks.

## Runner and version evidence

- The Robot runner now prepends its local package root before importing the version module. This prevents an older installed/editable copy from being reported instead of the archive being executed.
- Added `run_robot_criteria_boundaries.bat` for focused `BND-001..005` execution.

## Evidence improvements

- Heap, OFF-resistance, accuracy and stability metrics now include remaining pass margin where applicable.
- HIL guard-band results identify the closest mask and remaining margin.
- Coverage and Robot mapping tables include all new tests.

## Packaging

The internal archive root remains exactly `RegressionTest/`. Robot Framework remains the only supported user-facing runner.
