# E-Resistor Regression Test v2.5.2

## Scope change

Arduino CLI integration has been completely removed from the regression package.
The package no longer discovers, configures, launches, or validates a firmware compiler.

## Preserved functionality

- Pure-Python runtime regression profiles
- Robot Framework runtime regression profiles
- Ethernet HTTP and SCPI tests
- RP2040 USB CDC diagnostic capture
- USB/VISA DMM single-channel HIL measurements
- Read-only, safe-output and single-channel HIL safety interlocks
- Offline firmware source metrics and optimization-gate structure checks
- Baseline comparison, coverage, evidence manifests and software-version logging

## Interface changes

- `source_build` was renamed to `source_check`.
- `run_python_source_build.bat` was replaced by `run_python_source_check.bat`.
- `run_robot_source_build.bat` was replaced by `run_robot_source_check.bat`.
- `--arduino-cli` and `--fqbn` were removed from both launchers.
- `ERESISTOR_ARDUINO_CLI` and `ERESISTOR_FQBN` were removed from bench configuration.
- `BUILD-001` and all firmware-compilation evidence were removed.

Firmware compilation must be performed and validated separately in the firmware repository.
