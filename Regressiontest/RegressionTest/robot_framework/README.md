# E-Resistor Robot Framework runner

Supported profiles: `read_only`, `safe_output`, `hil_single_channel`, `gate3_transport_fault`, `gate4_profile`, `gate4_profile_fault`, and `gate5_service`.

Gate 5 targets firmware 0.8.0. Run the top-level BAT launchers on Windows. The internal Python package is implementation support for Robot Framework and is not a user-facing alternate runner.
